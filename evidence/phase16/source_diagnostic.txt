     During source ingestion, adapter.fetch() returns raw dictionaries (e.g. Dict[str, Any]).
     In the historical unhardened execution path, raw dict items were either directly inspected

     (item.id instead of item['id']), Python raised AttributeError: 'dict' object has no attribute 'id'.

D. ERROR SANITIZATION & CATEGORIZATION DEFECT:
   - When the AttributeError was caught, the exception handler executed str(e), yielding "'dict' object has no attribute 'id'".
   - The string was passed to sanitize_error("..."). Because the exception type name "AttributeError" was not included in str(e), classify_error_category() could not match the regex for AttributeError, categorizing it as "unknown_error".
   - The UI then formatted and truncated this as "[unknown_error] 'dict' object has no attribute 'i...".
